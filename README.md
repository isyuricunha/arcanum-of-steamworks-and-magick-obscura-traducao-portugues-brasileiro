# Tradução em Português Brasileiro para Arcanum: Of Steamworks and Magick Obscura

> **Participe da comunidade no Discord:** <https://discord.gg/uFEwSMwUYb>

## 📦 Instalação da Tradução

Este é um guia **detalhado** passo a passo para instalar a tradução em Português Brasileiro para o jogo Arcanum. Siga as instruções cuidadosamente.

---

### 🔧 Requisitos

1. **Jogo Arcanum instalado** - Você precisa ter o jogo Arcanum: Of Steamworks and Magick Obscura instalado em seu computador
2. **Arquivo de tradução** - Baixe o arquivo `translated_ptbr.7z` ou `translated_ptbr.zip` das [releases](https://github.com/isyuricunha/arcanum-of-steamworks-and-magick-obscura-traducao-portugues-brasileiro/releases)
3. **Programa para extrair arquivos** - Você precisará de um programa como:
   - [7-Zip](https://www.7-zip.org/) (recomendado)
   - WinRAR
   - WinZip
   - O descompactador padrão do Windows

---

### 📥 Passo 1: Baixar a Tradução

1. Acesse a página de [releases](https://github.com/isyuricunha/arcanum-of-steamworks-and-magick-obscura-traducao-portugues-brasileiro/releases)
2. Na seção "Assets", clique em `translated_ptbr.7z` ou `translated_ptbr.zip` para baixar
3. Escolha um local fácil de encontrar (como a área de trabalho ou pasta de downloads)

---

### 🗂️ Passo 2: Extrair os Arquivos

**Método 1: Usando 7-Zip**

1. Clique com o botão direito no arquivo `translated_ptbr.7z` ou `translated_ptbr.zip`
2. Selecione "7-Zip" > "Extrair aqui" ou "Extrair para translated_ptbr\"
3. Uma pasta chamada `translated_ptbr` será criada

**Método 2: Usando o Windows Explorer**

1. Clique duas vezes no arquivo `translated_ptbr.zip`
2. Clique em "Extrair tudo" no menu superior
3. Escolha um local para extrair (como a área de trabalho)
4. Clique em "Extrair"

**Método 3: Usando WinRAR**

1. Clique com o botão direito no arquivo
2. Selecione "Extrair aqui" ou "Extrair para translated_ptbr\"
3. Aguarde a extração ser concluída

---

### 🎮 Passo 3: Localizar a Pasta do Jogo

Você precisa encontrar onde o jogo Arcanum está instalado em seu computador. O local pode variar dependendo de onde você instalou:

**Locais comuns:**

- `C:\Program Files (x86)\Steam\steamapps\common\Arcanum`
- `C:\GOG Games\Arcanum`
- `C:\Jogos\Arcanum`
- `C:\Arcanum`

**Como encontrar manualmente:**

1. Abra o Windows Explorer (tecla Windows + E)
2. Na barra de pesquisa, digite "Arcanum" e pressione Enter
3. Procure pela pasta que contém o arquivo `Arcanum.exe`
4. Dentro dessa pasta, você verá uma pasta chamada `data`

---

### 📁 Passo 4: Copiar os Arquivos da Tradução

1. Abra a pasta `translated_ptbr` que você extraiu
2. Você verá **3 pastas**:
   - `dlg` (diálogos)
   - `mes` (mensagens)
   - `rules` (regras)

3. **Selecione as 3 pastas** (clique em uma, segure Ctrl e clique nas outras duas)
4. Copie as pastas (Ctrl + C ou clique direito > Copiar)

5. Navegue até a pasta `data` do jogo Arcanum
6. Cole as pastas dentro da pasta `data` (Ctrl + V ou clique direito > Colar)

7. **Importante:** Quando perguntado se deseja substituir arquivos, clique em **"Sim para todos"**

---

### ✅ Passo 5: Verificar a Instalação

1. Abra a pasta `data` do jogo
2. Verifique se as pastas `dlg`, `mes` e `rules` estão presentes
3. Abra cada pasta e verifique se há arquivos dentro delas
4. Inicie o jogo e verifique se os textos estão em Português

---

### 💡 Dicas e Solução de Problemas

**Problema: Não consigo encontrar a pasta do jogo**

- Tente procurar por "Arcanum.exe" no Windows Explorer
- Se você instalou pelo Steam, clique com o botão direito no jogo > Propriedades > Arquivos locais > Procurar arquivos locais

**Problema: O jogo não está em Português**

- Verifique se você copiou as pastas para o local correto (`Arcanum\data`)
- Certifique-se de que substituiu os arquivos existentes
- Tente reiniciar o jogo

**Problema: Arquivos corrompidos**

- Baixe novamente o arquivo de tradução
- Extraia novamente usando um programa diferente (recomendamos 7-Zip)
